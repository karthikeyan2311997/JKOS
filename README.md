# JKOS — Personal Portfolio Website

**Architect × Developer × Creative Technologist**

A minimal, modern personal portfolio website showcasing the professional journey, architectural practice, creative explorations, technical capabilities, and selected works of Karthikeyan J K.

🌐 **Live Website:** https://jkosv1.vercel.app

---

## 1. Overview

JKOS is a personal digital portfolio designed to bring together architecture, technology, design thinking, and creative experimentation under one digital identity.

The website serves as a central platform to present professional experience, selected projects, design capabilities, technical interests, and personal explorations.

It bridges the disciplines of the built environment and digital development, reflecting an interdisciplinary approach to contemporary design.

## 2. Objectives

* Establish a unified personal digital identity.
* Showcase architectural and design projects.
* Present technical and software development capabilities.
* Document creative experiments and explorations.
* Provide a professional point of contact.
* Create a responsive experience across desktop, tablet, and mobile devices.

## 3. Website Structure

The website is intended to accommodate the following content categories:

* **Introduction:** Personal introduction and professional identity.
* **About:** Background, experience, philosophy, and professional journey.
* **Architecture:** Selected architectural projects and design explorations.
* **Development:** Software development, digital products, and technical experiments.
* **Creative Works:** Visual experiments, research, and interdisciplinary projects.
* **Experience:** Professional experience and collaborations.
* **Contact:** Professional enquiries and communication channels.

## 4. Design Philosophy

The website follows a minimal digital design approach, prioritising:

* Clear visual hierarchy.
* Typography-driven layouts.
* Generous whitespace.
* Minimal and purposeful interactions.
* Responsive composition.
* Consistent visual language.
* Performance-conscious implementation.

The interface is intended to complement the interdisciplinary nature of architecture and technology.

## 6. Project Setup

### Prerequisites

* Node.js
* npm or an equivalent package manager
* Git

### Installation

Clone the repository:

```bash
git clone <repository-url>
```

Navigate into the project:

```bash
cd <project-folder>
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

### Production Build

Generate the production build:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

## 7. Deployment

The website is deployed using Vercel.

Typical deployment workflow:

1. Push the source code to GitHub.
2. Import the repository into Vercel.
3. Configure the build command.
4. Configure the output directory.
5. Deploy the production build.
6. Connect a custom domain if required.
